# 인프라 OJT 가이드 (웹/앱)

OJT 녹취록을 업무 가이드로 정리한 **정적 웹앱(PWA)** 입니다. 빌드 도구 없이 HTML/CSS/JS만으로 동작하며, 모바일에서는 "홈 화면에 추가"로 앱처럼 설치할 수 있습니다.

## 구성

| 메뉴 | 내용 |
|---|---|
| 핵심 원칙 | 금융 IT에서 일하는 방식(규정→절차→실행, ‘관리’의 의미 등) |
| 인프라 구조 | 센터 6곳, 망 구분, 핵심 수치 |
| 업무 흐름 | 주문·뱅킹·시세·인증·통합로그·DR 흐름도 |
| 용어·시스템 사전 | 약어·제품명 50여 개(분류 필터) |
| 넥스트 IT | 배경·원칙·일정·9대 과제 |
| 클라우드 | 도입 절차·현황·운영 업무 |
| 운영 프로세스 | 정기/상시 절차 13종과 증적 |
| 협업 R&R | 조직별 역할·협업 팁 |
| 진행 과제·대안 | 과제별 대안 3가지 + 추천 + 개인 메모 |
| 확인 필요 / 학습 로드맵 / 셀프 퀴즈 | 검증 목록, 30·60·90일 체크리스트, 퀴즈 |

- 상단 검색창: 전체 내용 검색
- 체크 진도·메모: 브라우저(localStorage)에만 저장, 좌측 하단에서 JSON 내보내기/가져오기
- 다크 모드, 오프라인 캐시(Service Worker)

## 내용 수정

모든 내용은 `js/data.js` 한 파일에 있습니다. **이 저장소는 공개 저장소라서 `js/data.js`(평문)는 커밋하지 않습니다(.gitignore).** 저장소에는 암호화된 `data.enc.json`만 있고, 앱은 `js/data.js`가 없으면 암호 입력 화면을 띄웁니다.

수정 절차:
1. 따로 보관한 `js/data.js`를 `js/` 폴더에 넣고 수정 (로컬에서는 암호 없이 바로 열림)
2. `node tools/build-secure.mjs "<암호>"` 실행 → `cp dist/data.enc.json .`
3. `data.enc.json`만 커밋

## ⚠️ 보안 — 공개 호스팅 전에 꼭 읽어 주세요

이 가이드에는 **사내 인프라 구성(센터, 망 구조, 시스템명, 용량, 계약 정보)** 이 들어 있습니다. 금융회사 내부 정보이므로 그대로 공개 사이트에 올리면 정보보호 규정 위반 소지가 있습니다. 업로드 전 IT보안팀 기준을 확인하시고, 아래 방식 중 하나를 권장합니다.

### 암호화 빌드 (권장)

```bash
node tools/build-secure.mjs "10자-이상-긴-암호"
```

- `dist/` 폴더가 생성되며, 내용은 AES-256-GCM(PBKDF2 31만 회)으로 암호화된 `data.enc.json`으로만 들어갑니다.
- **`dist/` 폴더만** 업로드하세요. 평문 `js/data.js`는 포함되지 않습니다.
- 암호는 메신저 등 별도 채널로 공유하고, 추측하기 어려운 긴 문장을 쓰세요.

## 무료 호스팅 방법

| 방법 | 절차 | 비고 |
|---|---|---|
| **Netlify Drop** | app.netlify.com/drop 에 `dist/` 폴더를 드래그 | 가장 간단, Git 불필요 |
| **Cloudflare Pages** | 대시보드 → Pages → Direct Upload로 `dist/` 업로드 | Cloudflare Access(무료 50명)로 이메일 인증 접근 제한 가능 |
| **GitHub Pages** | 별도 저장소에 `dist/` 내용만 push → Settings → Pages | 공개 저장소면 소스가 노출되므로 반드시 암호화 빌드만 올릴 것 |

> 이 저장소는 평문 데이터를 포함하지 않으므로 그대로 GitHub Pages(Settings → Pages → Branch 선택, `/root`)로 배포해도 암호 화면이 먼저 나옵니다.
